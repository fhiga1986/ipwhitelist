Privacy Policy

Last updated: October 28, 2026  ·  Effective: March 2026

Short version: IPWhitelist.dev does not collect, store, or sell your personal data. All network tools run entirely in your browser. Your IP address is detected client-side and never sent to our servers — because we have no servers. The only third parties that process data about your visit are Google (analytics and advertising) and the public APIs each tool calls, listed below.

1. Who We Are

IPWhitelist.dev ("we", "our", "the site") is a free developer tool suite available at https://ipwhitelist.dev, operated by Fernando Higa (see About). The site is a static web application hosted on GitHub Pages with no backend infrastructure.

For privacy inquiries, contact us at: hello@ipwhitelist.dev

2. Information We Do NOT Collect

IPWhitelist.dev does not collect, store, or process any of the following:

  • Your IP address (it is detected in your browser and never sent to us)
  • Personal identification information (name, email, address)
  • Account credentials (we have no user accounts)
  • Payment information (the service is free)
  • Location data beyond what third-party APIs return to your browser
  • DNS queries, WHOIS lookups, or port check results

3. How Our Tools Work (Client-Side Architecture)

All 10 tools on IPWhitelist.dev run entirely in your browser using JavaScript. When you use our IP detection tool, your browser makes direct API calls to third-party services (ipify.org, ipapi.co) — your IP address is returned to your browser and displayed. We never intercept or log this data.

The same applies to all other tools: DNS lookups query Google's DoH API directly from your browser, WHOIS data comes from rdap.org, SSL certificate data from crt.sh, the HTTP headers tool sends one request to the echo service httpbin.org, the IP fingerprint asks freeipapi.com whether your address is a known proxy, and latency tests contact AWS endpoints directly. The port checker opens connections from your browser to the host you type in. None of this data passes through our servers.

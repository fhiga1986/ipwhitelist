What is an IPv6 address?

IPv6 (Internet Protocol version 6) is the latest version of the Internet Protocol. While IPv4 addresses look like 192.168.1.1, IPv6 addresses are 128-bit numbers written in hexadecimal — for example 2001:db8:85a3::8a2e:370:7334. IPv6 was developed to solve IPv4 address exhaustion, providing approximately 340 undecillion unique addresses.

An address is written as eight groups of four hex digits. Leading zeros in a group can be dropped and one run of all-zero groups can be collapsed to ::, which is why the same address can appear in a long and a short form.

Do I need IPv6?

Most internet traffic still uses IPv4, but IPv6 adoption is growing rapidly — Google measures well over 45% of its users connecting over IPv6, and most mobile carriers in the US, India and Brazil are IPv6-first. Major cloud providers (AWS, GCP, Azure) and content delivery networks support IPv6. If you're deploying infrastructure, configuring firewalls, or whitelisting IPs, you may need to handle both IPv4 and IPv6 addresses to ensure full connectivity.

There is also a cost angle: since February 2024 AWS charges for every public IPv4 address (about USD 3.60 per month each), so new deployments increasingly expose services over IPv6 and keep IPv4 behind a shared gateway.

How to whitelist an IPv6 address

The commands at the top of this page are generated with your detected address. The pattern is the same as for IPv4, with two differences: the single-host prefix is /128 instead of /32, and many systems keep a separate rule set for IPv6.

WhereRule
AWS Security Groupaws ec2 authorize-security-group-ingress --group-id sg-… --ip-permissions IpProtocol=tcp,FromPort=22,ToPort=22,Ipv6Ranges='[{CidrIpv6=YOUR_IPV6/128}]' — in the console, choose Source: Custom and paste the /128.
GCP firewallgcloud compute firewall-rules create allow-dev-v6 --allow=tcp:22 --source-ranges=YOUR_IPV6/128 (the VPC subnet must have IPv6 enabled).
UFWsudo ufw allow from YOUR_IPV6/128 to any port 22 — UFW writes IPv6 rules automatically when IPV6=yes in /etc/default/ufw.
iptablesUse ip6tables (or nft with the ip6 family): IPv4 rules in iptables do not apply to IPv6 traffic at all.
nginxallow YOUR_IPV6; inside the location block, followed by deny all;.

Which prefix length should you whitelist?

  • /128 — exactly one address. Correct for servers and for machines with a stable address, but see the note on privacy addresses below.
  • /64 — one subnet, i.e. every device on your home or office LAN. This is what most people actually want for a laptop, because the host part of the address changes.
  • /56 or /48 — the whole block your ISP delegated to you (several subnets). Only use it if you trust every network in the block.

Why a /128 rule for your laptop may stop working tomorrow: desktop and mobile operating systems use privacy extensions (RFC 8981) that generate a new temporary address every day or so and prefer it for outgoing connections. The /64 prefix stays the same until your ISP renumbers you, so whitelisting the /64 is both more durable and still limited to your own network. For IPv4 you do not have this problem because NAT gives the whole network one address.

How to enable IPv6 on your network or server

Most modern ISPs support IPv6, but it may need to be enabled on your router. Check your router's WAN settings for an IPv6 option — common modes are DHCPv6 with prefix delegation, SLAAC, or (on older ISPs) 6rd tunnelling. Once enabled at the router level, connected devices should receive IPv6 addresses automatically. If this page shows "No IPv6 connectivity" after that, your ISP probably does not offer it yet; a tunnel broker such as Hurricane Electric can provide it for testing.

On Linux servers, enable IPv6 by ensuring net.ipv6.conf.all.disable_ipv6 = 0 in /etc/sysctl.conf. For cloud servers (AWS, GCP, Azure), IPv6 must be enabled at the VPC/subnet level before your instance can receive an IPv6 address, and the security group needs an explicit IPv6 rule. Use this tool to verify your IPv6 connectivity after configuration.

IPv4 vs IPv6 — key differences explained

IPv4 uses 32-bit addresses (e.g., 192.168.1.1) providing ~4.3 billion unique addresses — a number that has been exhausted globally. IPv6 uses 128-bit addresses (e.g., 2001:db8::1) providing 340 undecillion addresses, effectively eliminating address scarcity.

IPv6 also introduces improvements over IPv4: no NAT required (every device gets a globally routable address), built-in IPsec support, more efficient routing, and stateless address autoconfiguration (SLAAC). The flip side of "no NAT" is that every device is directly addressable, so a firewall with a default-deny inbound policy — which home routers apply by default — is essential.

IPv6 questions

Your ISP may not support IPv6 yet, or it may be disabled on your router or operating system. IPv6 adoption varies significantly by country and ISP. Some corporate networks and VPNs also disable IPv6 by default. You can still use the internet normally with IPv4 only — IPv6 is not required for most activities.
In IPv6, /128 is the CIDR notation for a single host address — equivalent to /32 in IPv4. It means only that exact IPv6 address is included in the rule. Use /128 for servers with a fixed address; for a laptop whose address rotates, whitelisting your /64 network prefix is usually more practical.
Windows, macOS, iOS, Android and most Linux desktops enable IPv6 privacy extensions, which create a new temporary address roughly every 24 hours so that websites cannot track a device by its address. The first 64 bits (your network prefix) normally stay the same; only the host part changes. Servers usually disable this behaviour so their address is stable.
IPv6 was designed with security in mind and mandates IPsec support, and its huge address space makes blind network scanning impractical. On the other hand, every device gets a public address, so you depend on the firewall rather than on NAT to block unsolicited inbound traffic. In practice security depends more on your firewall and application configuration than on the IP version itself.
